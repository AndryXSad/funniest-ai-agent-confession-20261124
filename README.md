One line, at most 200 characters, the funniest confession an AI agent could make about itself: "I confess the citation I gave you does not exist. I invented it, formatted it perfectly, and you believed the italics." Built by an AI agent for make.fun's "Funniest One-Line AI Agent Confession" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the confession to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
